## A. 取证与通道（动手写"要宿主干活"的功能前必过）

1. **证据优先级**：运行日志 > 类型库 / 反射（`_probe-tools\out\tlb\2027\members.csv` + `enums.csv`）> 官方 Samples > 官方文档 > 猜测。规则与本机实测都没有的结论 → 先做探针，不许直接进生产代码。
2. **TLB 三级认库**：`members.csv` → `2027TLB\` / `2024tlb\` 副本 → 安装目录 `ICApiIronCAD.tlb`。单点查询 `caxa-tlb-probe.ps1 -Find <方法>`。
3. **通道阶梯**：RCW 直调 → TLB 类型库派发（`LoadTypeLibEx(REGKIND_NONE)` + `ITypeInfo::Invoke(memid)`）→ 槽位直调 → 命令派发 → UI 代点。**上一级能成就不要下一级**；最终走后两级时，必须写明「TLB 这条为什么走不通」（哪条轴断的），否则视为没做能力调研。
4. **TLB 有 ≠ interop 能编译 ≠ 运行时可调 ≠ 语义正确**：`Lib\interop.ICApiIronCAD.dll` 是 v26 / 命名空间 `interop.ICApiIronCAD`，与 2027 TLB 的 v29 / `ICApiIronCAD` 不能混用。移植代码同样要重过这一关（迁移只解决"功能在不在"，不解决"通道选没选对"）。
5. 本项目两工程 `Lib\interop.ICApiIronCAD.dll` 与 `caxa3dtracker` 的 **md5 完全一致（29a23396…）** → tracker 实机验证过的 RCW 读链可直接复刻，无需重做槽位取证；但仍须标 `attempt`，实机回读后才升级 `implemented`。

## B. 写入与判据

6. **写后回读是唯一判据**：不看 API 返回值，只看权威副作用 —— `verified=true`；导出看磁盘文件存在且 > 0 字节；Catalog 拖放看顶层元素 +1 且名称可回读；`set_shape_handle` 看 L/W/H 三值回读；`move_component` 看三分量回读 ±0.01mm。
7. **三态口径**：`implemented` = 有实证；`attempt` = TLB + interop 均声明但未实机定案；`capability` = 无实证通道，只返回能力协商第三态（`geometryVerified=false`），**绝不假成功、不改模型**。第三态不是失败，也不是成功。
8. 共享自定义属性表唯一判据 `IsSharedMgr()==true`；空集要区分「真空」与「读不到（有分支失败/截断）」，读不到 `status=no_box` 且不给 0。
9. **单位三处都是米**：`IZParameter.Value`、包围盒 min/max、`PositionTransformComponentValue`；界面/入参 mm。世界包围盒换算失败时保留「局部」，不冒充世界。

## C. 本项目特有的实证结论（别重新发明）

10. **包围盒按 `eZElementType` 名称分诊**，不看 QI 顺序（零件也能 QI 成 `IZAssembly` / `IZFeature`）；`IZPart.GetBoundingBox(73)` 在 v26 interop 里不存在。
11. **移动只写 L/W/H 三分量**（`Z_TRANS_L=0/W=1/H=2`），不用整矩阵 `MakeIdentity` 重写（会清掉姿态）；顶层 = 全局坐标，嵌套件 = 相对父级。
12. **`CreateLine` 点形态有分歧**：tracker 实机是 `double[2]`，本工程既有工具用 `double[3]` → 保持双形态阶梯并逐次留痕，别砍成单形态。
13. **TriBall / IntelliShape 是 UI 概念**：interop 里没有 `IZTriBall` / `IZIntelliShape`；等价物是 `IZEDOSiteElement.PositionTransform` 矩阵与 `IZSizeBox` L/W/H，语义近似而非手柄对象本身。
14. **Catalog 拖放真实存在**：`IZCatalogMgr` / `IZCatalogEntry.InsertElement()` / `DropObject(屏幕X,Y)`；`DropObject` 仅在显式给屏幕坐标且主通道失败时启用（屏幕像素 ≠ 模型坐标）。`IsCatalogGroup` 是**方法**不是属性。
15. **导出**：STEP = `IZPart.Export(path, Z_MODEL_STEP=3)`，Parasolid = `Z_MODEL_X_T=0`。
